# `shake`

Shake is a function to apply a shake effect to an element.

```ts
function shake(cb: (val: number) => void, itensity?: number): ThreadGenerator;
```

# `ShakeSpring`

`ShakeSpring` is the spring used for `shake`:

```ts
function ShakeSpring(intensity?: number): Spring;
```
